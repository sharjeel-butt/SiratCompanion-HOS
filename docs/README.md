# Sirat Companion — Privacy Policy

This folder hosts the public privacy policy for **Sirat Companion**, an Islamic companion app for HarmonyOS.

The rendered policy is available at:

**https://sharjeel-butt.github.io/SiratCompanion-HOS/**

## About Sirat Companion

Sirat Companion is an offline-first Islamic companion app featuring:

- Prayer times with multiple calculation conventions
- Qibla compass
- Tasbih (dhikr counter)
- Hijri calendar
- Prayer notifications

The app does not collect, transmit, or share any personal information. All data stays on the user's device.
